# 02 — Learning Validation Plan

## Propósito de este documento en el laboratorio

Este documento define cómo validar si Agent Experience Simulator aporta **valor pedagógico real**, no solo viabilidad técnica.

La pregunta ahora es:

> ¿Una experiencia simulada ayuda a una persona no técnica a comprender mejor cómo trabajar con IA?

## 1. Hipótesis

> A learner can understand an AI-assisted workflow more clearly by completing an interactive simulated agent experience than by only watching a passive demonstration.

## 2. Qué no validamos todavía

No buscamos demostrar aún:

- product-market fit completo;
- pricing;
- escalabilidad empresarial;
- cientos de cursos;
- analytics avanzados;
- LMS;
- adaptive AI.

## 3. Primera experiencia educativa real

Ejemplo recomendado:

**Create an Executive Summary with AI**

Debe incluir:

- prompt realista;
- datos ficticios;
- actividad visible;
- output determinista;
- recursos;
- instrucciones claras.

## 4. Participantes

Primera ronda:

```text
5–10 participantes
```

Preferentemente:

- no desarrolladores;
- experiencia limitada o intermedia con IA;
- profesionales de oficina, análisis, operaciones o gestión.

## 5. Sesión

### Parte A — Contexto
Explicar la tarea brevemente.

### Parte B — Experiencia
Observar dónde duda, qué ignora y qué intenta hacer.

### Parte C — Preguntas

1. ¿Qué hizo el agente después de recibir el prompt?
2. ¿Cuál fue el resultado principal?
3. ¿Qué recursos produjo?
4. ¿Qué parte quedó más clara?
5. ¿Qué parte fue confusa?
6. ¿Sentiste que ejecutabas una tarea o veías una animación?
7. ¿Te sentirías más preparado para hacerlo después en una IA real?
8. ¿Preferirías esta experiencia a un video de la misma tarea?
9. ¿Por qué?

## 6. Señales a registrar

```text
understood workflow
understood prompt purpose
understood output
noticed resources
felt interaction
felt confidence
confusion points
wanted additional control
```

## 7. Escala opcional 1–5

- Clarity
- Realism
- Usefulness
- Engagement
- Confidence after exercise

## 8. Señales positivas

- "Ahora entiendo qué esperar."
- "Me quedó más claro que con el video."
- "Quiero probarlo yo mismo."
- "Pude seguir lo que estaba haciendo."

## 9. Señales de alerta

- "Solo parecía un video."
- "No entendí qué pasaba."
- "Pensé que era IA real y me confundió."
- "No sabía qué debía observar."

## 10. Interpretación

### A — Strong Signal
Continuar creando laboratorios y evaluar Stage 2.

### B — Useful but Passive
Explorar interacción pedagógica o branching simple.

### C — Confusing
Corregir UX, ritmo e instrucciones antes de agregar features.

## 11. Resultado

Documentar:

```text
What learners understood
What confused them
What they valued
What they requested
What we should change
What we should not build yet
```

## 12. Criterio para avanzar

Agregar capacidades solamente cuando:

1. el formato haya demostrado valor;
2. los usuarios comprendan la experiencia;
3. exista una limitación concreta que una nueva capacidad pueda resolver.
