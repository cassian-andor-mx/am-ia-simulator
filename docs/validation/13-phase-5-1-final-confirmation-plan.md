# Phase 5.1 — Final Confirmation Plan

## Propósito de este documento en el laboratorio

Validar únicamente los dos asuntos restantes de Phase 5.

No es otra ronda completa.

## Participants

Recommended:

```text
2–3 participants
```

## Toolbar questions

Ask:

1. Does AI Usage feel like it belongs to the widget now?
2. Is its location natural?
3. Does it look different enough from Prompt / Simulation / Resources?
4. Is it still easy to notice after completion?

Success:

- natural location;
- understood as utility/status, not navigation.

## Environmental methodology question

Ask exactly:

> Is this measuring the real environmental impact of this exact simulated interaction?

Expected:

> No. It is a reference estimate, not a measurement of this exact run.

## Distraction

Ask:

> Does AI Usage distract you from the main exercise?

Expected:

Low/no distraction.

## Outcome

- `VALIDATED`
- `MINOR COPY ADJUSTMENT`
- `MINOR PLACEMENT ADJUSTMENT`
- `METHODOLOGY CUE STILL UNCLEAR`
