## Structured Question Notes

### What learners understood

- Prompt to Simulation workflow is clear.
- Simulation tab behavior is understandable.
- Output is concise and decision-oriented.

### What confused learners

- Expected a free-text prompt box like common agent tools.
- Expected a darker "black screen" style associated with some agent UIs.
- Three-tab model differs from a single chat-field mental model.

### What they valued most

- Short and clear output focused on decisions.
- Visible sense that the system is processing information.
- Easy replication of a practical workflow.

### What they requested

- More interaction opportunities.
- Ability to introduce variables in prompts.
- Smaller visual footprint (compact widget instead of large panel).

### What should change

- Improve interaction perception after repeated runs.
- Improve visual familiarity without coupling to a provider.
- Reduce dominant layout footprint.

### What should not be built yet

- Large roadmap expansions are not required yet.
- Preserve incremental scope and deterministic scripted baseline.

## Outcome Classification

- Result bucket: `USEFUL BUT PASSIVE`
- Rationale: Learners clearly understood workflow, prompt purpose and outputs, and reported strong confidence gains; however, repeated runs felt static and participants requested controlled interaction improvements.
