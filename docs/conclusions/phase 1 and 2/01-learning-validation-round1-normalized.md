## Qualitative Findings

### What learners understood

- Prompt to Simulation workflow is clear.
- Simulation tab behavior is understandable.
- Output is concise and decision-oriented.

### What learners valued most

- Short and clear output (not overloaded with irrelevant details).
- Visual feeling that the system is processing data.
- Easy replication of the demonstrated role/workflow.

### What confused learners

- Expected a free-text prompt box like common agent tools.
- Expected a darker/"black screen" style commonly associated with some agent UIs.
- Three-tab model differs from "single chat field" mental model.

### What learners requested

- More interaction opportunities.
- Ability to introduce variables in prompts.
- Smaller visual footprint: simulator should feel more like a compact widget and less like a large panel.

### What should change (normalized)

- Improve interaction perception after repeated runs.
- Improve visual familiarity without coupling to any specific provider.
- Reduce dominant layout footprint on screen.

### What should not be built yet (normalized)

- Large roadmap expansions are not required yet.
- Current scope is still useful for learning and should remain incremental.

## Risk and Opportunity Summary

- opportunity_primary: strong clarity and confidence outcomes
