# Phase 5 Entry Decision

## Propósito de este documento en el laboratorio

Este documento registra formalmente la entrada a **Phase 5 — Usage Meter UX Refinement & Transparency** y preserva el significado correcto de la mini-validación de Phase 4.

## 1. Phase 4 Outcome

Phase 4 delivered:

- Read-only Prompt Composer;
- AI Usage Meter;
- token usage details;
- environmental reference profile;
- responsible-AI demo;
- methodology documentation.

Mini-validation outcome:

`VISUAL REFINEMENT NEEDED`

Secondary risk:

`METHODOLOGY COMMUNICATION ISSUE`

## 2. Validation Findings

Positive:

- AI Usage is noticed;
- learners care about responsible AI usage;
- environmental information creates reflection;
- the feature is relevant.

Problems:

- meter is visually too large;
- it competes with the simulation result;
- details are too technical;
- input/output token terminology is not intuitive;
- environmental figures may be trusted before methodology is understood.

## 3. Approved Direction

Phase 5 will:

1. reduce AI Usage prominence;
2. move it to a utility position;
3. keep it neutral while running;
4. activate it after completion;
5. simplify details;
6. explain token concepts in plain language;
7. separate estimated/reference environmental values clearly from measured usage.

## 4. Existing Concepts That Remain

Preserve:

- token metrics;
- interaction-load bands;
- environmental reference profile;
- methodology source;
- details-on-demand;
- deterministic behavior.

The methodology stays intact. Only default presentation becomes simpler.

## 5. Out of Scope

Do not add:

- exact carbon claims;
- universal tokens-to-CO2 formulas;
- gamification;
- environmental rankings;
- good/bad user scoring;
- live pricing;
- live model telemetry;
- model comparison dashboards;
- new AI integrations.

## 6. Product Principle

> Complexity should remain available without being visible by default.

## 7. Success Definition

Users should:

- notice AI Usage without distraction;
- understand the usage band;
- understand `You asked` vs `AI returned`;
- understand environmental information is reference-based;
- access deeper methodology if interested;
- remain focused on the learning task.
